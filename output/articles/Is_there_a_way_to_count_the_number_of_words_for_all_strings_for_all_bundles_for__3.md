# Is there a way to count the number of words for all strings for all bundles for a specific language on a production instance?

When create a RTR, there is `DELTA WORD COUNT` for the new language  
for each bundle, it is all words for a  completely  new language.

![](media_files/image-png-Jun-24-2024-06-11-27-7990-AM.png)

You can see the total word count for the new language of all bundles on **Basic information section**when create a draft RTR:

![](media_files/image-png-Jun-24-2024-06-11-54-2098-AM.png)
