# Git credentials management

Go to <https://file-access.g11n.ibm.com/webfm> by clicking a link in WebFM or opening it directly in web browser.

![](media_files/image-png-Mar-02-2026-01-23-00-2236-AM.png)

#### Update existing credential

Click "Update" in existing credential item

![](media_files/image-png-Mar-02-2026-01-27-27-0510-AM.png)

Input a new generated token and click "Update"

![](media_files/image-png-Mar-02-2026-01-31-11-5909-AM.png)

#### Add a new credential

Click "Create git credential"

Input "Git ID" and "Git Token"

Click Submit

#### Verify git credential configuration and access

Go to or refresh WebFM application configuration page, check Git Credential option in repository connection setup.

Click Test Connection to verify the credential access.

### Github Personal access tokens setting

URL:

https://github.ibm.com/settings/tokens or https://github.com/settings/tokens

Reference:

https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens
