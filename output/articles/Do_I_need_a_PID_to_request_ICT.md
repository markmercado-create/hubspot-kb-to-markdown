# Do I need a PID to request ICT?

Yes. In fact, requesting ICT is nothing different from a regular translation request (TR) in Globalization Pipeline. In order to send a translation request, a UTL-20 and Product ID (PID) is required to be set up in your Globalization Pipeline profile as a billing data requirement.  If a PID is not available for some reason, GTECH team can assign a custom PID: the product development team needs to open a Translation L1 support issue like this https://github.ibm.com/1t1p/g11n-translation-L1/issues to request a custom PID. The custom codes are maintained by GTECH team and used by IDHub and Globalization Pipeline for billing code resolution/validation and translation memory lookup.
