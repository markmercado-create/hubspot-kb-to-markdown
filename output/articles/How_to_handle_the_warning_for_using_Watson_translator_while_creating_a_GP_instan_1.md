# How to handle the warning for using Watson translator while creating a GP instance?

While creating a GP instance, you may getting a warning for using Watson translator like this:

![](media_files/image-png-4.png)

This was designed for user who created a custom translation model. But there are no such user at this moment. Thus, don't override the WLT (watson language translation) configuration. GP has a default configured that the Translation Team pays for.
