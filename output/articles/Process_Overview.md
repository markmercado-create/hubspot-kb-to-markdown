# Process Overview

### Create a Globalization Pipeline instance

The Globalization Pipeline team will create one or two GP instances for an IBM internal team. Once GP instances are ready, the IBM internal team will receive credentials for accessing each GP instance that are created for the internal team. The credentials are in JSON format as below:

```
{  
  "url" : "https://g11n-pipeline-api.straker.global/translate/rest",  
  "userId" : "012d46c0421769b1e19f0a6b7ba3c2d5",  
  "password" : "uk9pjv/BbO2pd0OluLbyJf0wjp0V/Q4v",  
  "instanceId" : "app-xyz-prod"  
}
```

### Stand-alone service or integrated into DevOps?

As part of onboarding to Globalization Pipeline, you can use the services in multiple ways

- as a stand-alone IBM Cloud service (using the service dashboard), or
- integrate the service into your DevOps infrastructure.
