# Is MT API compliant to translate SPI and IBM Confidential data as well?

Google and DeepL free public licenses are definitely a problem. They use your data to "improve the service".

**Commercial licenses are OK.** They have data privacy language that is acceptable. Straker Translations has commercial licenses with the translation engines.
