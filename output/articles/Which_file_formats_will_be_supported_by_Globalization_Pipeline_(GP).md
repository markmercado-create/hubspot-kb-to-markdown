# Which file formats will be supported by Globalization Pipeline (GP)?

The file formats supported by Globalization Pipeline can be found [here](https://w3.ibm.com/w3publisher/globalization-pipeline/files-supported-types). If a file format you would like to use, is not listed on this page, you can use a custom filter (which may require you to develop it). For a complete list of all custom filter options and what they do, you can have a look [here](https://github.ibm.com/1t1p/gpv2-java-tools/blob/master/resource-filter/docs/customFilterOptions.md). If you don’t have any dependency on Globalization Pipeline, please contact with Straker Translations to check the file formats supported by them.
