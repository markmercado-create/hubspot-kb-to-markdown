# Tutorial videos show how to send translation request with attachments

### [**Translation with context workflow**📹](https://ibm.ent.box.com/file/1152615266987?s=l3wd7a6oxelxv4wylxdlfk1duysr0qzc)

This tutorial will introduce the workflow of translation with context by demonstrating the steps to create attachment container, upload attachment content (English screenshot), and associate an attachment with resource entry using Globalization Pipeline dashboard.

### [**How to perform attachment auto-association**📹](https://ibm.ent.box.com/file/1152609178456?s=4d9qa9lmzvjgxsvs09zp886n4dai108p)

In this video, it will demonstrate how to leverage en-XP pseudo translation screenshots to invoke the automatic association feature of Globalization Pipeline in the background. When screenshots are auto-associated with resource entries, user can check the auto-association result using the Globalization Pipeline dashboard. This demo will use [Globalization Pipeline command line interface tool](https://github.ibm.com/1t1p/gpv2-java-tools/tree/master/gp-java-tools/gp-cli) to complete the bulk upload process for en-XP pseudo translation screenshots.
