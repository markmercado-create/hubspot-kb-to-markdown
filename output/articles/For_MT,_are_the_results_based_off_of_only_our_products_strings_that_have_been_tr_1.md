# For MT, are the results based off of only our products strings that have been translated in the same language?

For new language, if other products in the same domain has the same segments translated in this language before, the memory will be reused for your product if it meets our memory reuse strategy. In general, the memory from the same product ID will be the first priority, then it comes to the memories in the same domain.
