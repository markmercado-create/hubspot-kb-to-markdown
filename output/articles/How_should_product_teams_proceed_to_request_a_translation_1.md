# How should product teams proceed to request a translation?

There are 3 engagement methods that apply to product teams.  

1. Onboard to WFM, and then submit the documentation through Workflow Manager (WFM)
2. Onboard to Globalization Pipeline, and then submit the UI strings through Globalization Pipeline (GP)
3. Submit an ad hoc requests through Translate@IBM using the Quick, Advanced or Premium option. Premium projects are assigned a globalization project manager who will work with you on estimates and return schedules.
