# If there are multiple link words in a message, can ordered tags be acceptable?

For example, the tag <a></a> and <a1>...</a1> in below source segment can be protected by GP.

```
"To add an integration id, go to <a1>OIDC providers</a1>. Or click <a2>here</a2> to generate one."
```
