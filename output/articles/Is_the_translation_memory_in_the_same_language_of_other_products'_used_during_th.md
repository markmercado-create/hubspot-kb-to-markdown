# Is the translation memory in the same language of other products' used during the machine translation of one product?

For a new language, if other products in the same domain has the same segments translated in this language before, the memory will be reused for your product if it meets GRTS memory reuse strategy. In general, the memory from the same product ID will be the first priority, then it comes to the memories in the same domain.
