# What's the way to submit a draft TR?

You can submit a draft TR (translation request) via GP dashboard, GP CLI or GP API, setting status to `DRAFT`.

- **GP dashboard:** https://g11n-pipeline-console.straker.global/login.wss
- **GP CLI:** <https://github.ibm.com/1t1p/gpv2-java-tools/tree/master/gp-java-tools/gp-cli>
- **GP API:** <https://g11n-pipeline-api.straker.global/translate/swagger/#/translation_request>
