# Can ONLY machine translation be used on UI?

Using ONLY machine translation (MT) on your UI is a horrible strategy!  MT is very good for sentence-based content, where there is sufficient context to translate properly. MT is a very risky strategy for UI labels and typical PII content. UI translation is not the place to cut spending. The few dollars saved is not worth the impact on customer perception of your product's quality. The Globalization/Translation Team has evaluated MT quality on UI and found it lacking. it's strongly recommended against this strategy.
