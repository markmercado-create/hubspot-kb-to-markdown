# How to solve error `chkpii -XM 904,903 (Reason: Missing Translation info. All Source info after line: 972 S: "...{0}..."},)`?

This Ezcheck error generally means that English file and translation file are inconsistent. If there are any problems with the translated files, please find and correct them.

On the other side, EzCheck is not mandatory in current translation process. You can bypass the error if you do not find any problem your translation file after review the error message and file. BTW, please make sure that English and translation files are at the same version level.
