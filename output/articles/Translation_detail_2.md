# Translation detail

GP introduces a new feature that displays the origin of each translation. A translation may come from one of the following sources:  
  

- Machine Translation
- Human Translation
- Translation Memory
- Code
- Do not translate
- User Provided

  
**How to view the translation detail?**  
  

1. From the GP Dashboard, open the translation of any resource entry.
2. Click the overflow menu (⋮), then select “Translation Detail” to view the source information.
