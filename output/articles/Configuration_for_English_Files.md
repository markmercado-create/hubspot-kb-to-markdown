# Configuration for English Files

1. Setup File Repository  

- [Task] Go to **Application Config** to setup file repository

2. Setup PII File List  

- [Task] Go to **PII File Config** to define English PII file list which you'd like to extract from file repository
- In **PII File Config**, user can configure which resource filter will be used for file importing and exporting from GP.  
  ![pii-config](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/pii-config.png)

3. Setup pre-translation process if needed
