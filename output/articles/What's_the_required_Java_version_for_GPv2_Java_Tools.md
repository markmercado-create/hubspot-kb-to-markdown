# What's the required Java version for GPv2 Java Tools?

The minimum required Java version for [gp-java-tools](https://github.ibm.com/1t1p/gpv2-java-tools) is **JDK 1.8.0\_261**. The tools may work with earlier versions (of Java 1.8) if necessary, but it is recommended to run at least 1.8.0\_261.
