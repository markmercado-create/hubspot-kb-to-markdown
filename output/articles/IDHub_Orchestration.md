# IDHub Orchestration

**Brief Overview:**  
WFM (WorkFlow Manager) interacts IDhub Orchestration for document translation, enabling efficient translation request handling through a set of APIs.

**How it works:**  
IDHub Orchestration is designed to enhance the translation process by offering multiple features that improve task handling and reduce redundancy:

1. **Translation Memory Domain Mapping:**  
   The system leverages historical translation data by mapping translation domains from PID. This allows for the reuse of previous translations, saving valuable time and effort.
2. **Job Duplication Checking:**  
   The system automatically checks for duplicated translation jobs, ensuring that each task is processed only once. This eliminates redundancy and ensures smoother workflow.
3. **Job Tracking:**  
   IDHub Orchestration tracks the history of translation jobs, allowing users to gain insights into past jobs and ensuring transparency in the translation process.
4. **Throughput Control:**  
   Throughput control helps manage the flow of translation requests, preventing the system from being overwhelmed and ensuring smooth processing under high workloads.
5. **Webhook Notification:**  
   The webhook notification feature keeps stakeholders updated in real-time on job status, ensuring constant communication and timely delivery of translation results.
