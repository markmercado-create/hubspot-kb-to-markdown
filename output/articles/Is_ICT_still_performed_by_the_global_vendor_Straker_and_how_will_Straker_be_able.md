# Is ICT still performed by the global vendor Straker and how will Straker be able to support the on-demand ICT requests without pre-booking in advance?

Yes.  ICT is requested from the Globalization Pipeline and is sent to the global vendor Straker in the same direct workflow as translation requests (TR). The ICT will be performed directly in the Straker Workbench with access to the PII files in the same environment for required translation updates.  Access to IBM environment is no longer required and therefore will allow Straker more flexibility for additional testing resources, better time management, and improved efficiency.
