# What are Resource Filters?

The format conversion to NVP is done via what GP calls **Resource Filter**s. GP has several built-in filters and the ability to customize and create your own if needed. See [Globalization Central](https://w3.ibm.com/globalization/) for the [docs on GP](https://w3.ibm.com/globalization/develop/globalizationpipeline).
