# Is there a way to count the number of words for all strings for all bundles for a specific language on my production instance?

When create a RTR, there is `DELTA WORD COUNT` for the new language  
for each bundle, it is all words for a  completely  new language. You can see the total word count for the new language of all bundles on **Basic information section**when create a draft RTR.
