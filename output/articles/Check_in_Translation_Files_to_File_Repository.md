# Check in Translation Files to File Repository

1. Go to **Work with English Files**, choose files, and click **Run GP Import/Export**  
![work-eng-files-3](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/work-eng-files-3.png)  
2. Check **Download Translations to WebFM (Export Bundle/File)**, select the languages, and click **Run GP**  
![gp-export](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/gp-export.png)  
![gp-export-output2](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/gp-export-output2.png)  
3. Go to **Upload File Manager**, choose packages, and click **UNZIP!**  
![unzip-package](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/unzip-package.png)  
4. Go to **Work with NLV Files** to check the translation files, and click **Run EzChecks** to run check PII (optional)  
5. On **Work with NLV Files** panel, check the EzChk Pass files, and click **Check-in** to check in translation files  
![work-nlv-checkin](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/work-nlv-checkin.png)  
![checkin-output](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/checkin-output.png)
