# File Check In Status Report

1. Go to **Report - File Check-In Status**  

![checkin-status-1](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/checkin-status-1.png)  
2. Choose the application(s) and the date, the report will include the files which were updated after the date  
![checkin-status-2](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/checkin-status-2.png)

3. Choose the report type, **By Language** or **All Language**, and click **Generate Report**  

4. The report can be sorted and changed status  
![checkin-status-3](https://20462040.fs1.hubspotusercontent-na1.net/hubfs/20462040/knowledge-base-files/webfm/checkin-status-3.png)
