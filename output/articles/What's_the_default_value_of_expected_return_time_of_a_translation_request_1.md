# What's the default value of expected return time of a translation request?

“expected return time” is set as TR priority.  

- 3 days = priority 5
- 5 days = priority 4
- 10 days = priority 2
- 15 days = priority 1

From GP Dashboard, we can select expected return time as below:  
![](media_files/image-png-Jun-11-2024-06-57-25-6099-AM.png)

Billing depends on delta word count, not the expected return time.
