# Client SDKs

There are client SDKs designed for accessing Globalization Pipeline APIs available on various runtime environment.

### Full Client SDKs

These client SDKs offer full access to Globalization Pipeline APIs. They can be integrated to application accessing translated resource at runtime, or creating custom build tool for modifying source and translated contents.

- NodeJS:  <https://github.ibm.com/1t1p/gp-js-client>
- GPv2 Java: <https://github.ibm.com/1t1p/gpv2-java-tools/tree/master/gp-java-client>

### Basic Client SDKs

These client SDKs offer read access to bundle contents and can be integrated to application accessing translated resource at runtime.

- Python: <https://github.ibm.com/1t1p/gp-python-client>
- Ruby: <https://github.ibm.com/1t1p/gp-ruby-client>
- Angular:
  - <https://github.ibm.com/1t1p/gp-angular-client>
  - <https://github.ibm.com/1t1p/gp-angular2-client>
- Cordova: <https://github.ibm.com/1t1p/gp-cordova-plugin>
