# Basic Info

### Introduction

The Web-based File Management Tool (WebFM) is a localization engineering tool used in the development and translation of localized files.

WebFM was designed to facilitate the file handling process by having a central web-based file management online tool. The tool allows users to create a project to monitor the changes to source PII files, extract the new/changed PII files from source repository, check them for translation readiness, and begin the process of delivering them for translation. After translation tasks are complete, WebFM can get translation back and check in translation files to target repository.
