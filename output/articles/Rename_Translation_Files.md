# Rename Translation Files

### -- Option 1 -- Renaming the Existing Files on WebFM

- [Task] Go to **Work with NLV files**, check the translation files and then click **Download as Zip** to download or **Check-in** to check-in to repository

### -- Option 2 -- Renaming the Uploaded Files

- [Task] Go to **Upload File Manager** to upload translation files manually, and click **UNZIP!**
- [Task] Go to **Work with NLV Files**, check the files, and click **EZ-Check** to run check PII
- [Task] On the **Work with NLV Files** panel, check the EzChk Pass translation files and then click **Download as Zip** to download or **Check-in** to check-in to repository
