# What is in scope for ICT via Globalization Pipeline, will testers still report defects not detected during GVT, for example translatability, correctness, appearance, mismatch, etc.

Straker testers will report defects like they do via the current ICT process.  The ICT defects found and collected by the testers will be communicated to the product development teams via the Globalization Pipeline dashboard.
