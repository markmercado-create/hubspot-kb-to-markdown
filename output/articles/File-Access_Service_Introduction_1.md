# File-Access Service Introduction

File-Access Service is a satellite-based service to access GitHub, which securely stores GitHub credentials  within the service infrastructure, and allow service providers to manage their own systems.

File-Access Service major features:

- Allow users to manage their GitHub credentials
- Provide APIs for WebFM to access files in Cloud Object Storage
- Provide APIs for WebFM to access GitHub repositories
