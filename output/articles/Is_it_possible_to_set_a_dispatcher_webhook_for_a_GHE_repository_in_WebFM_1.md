# Is it possible to set a dispatcher webhook for a GHE repository in WebFM?

The content type `application/x-www-form-urlencoded` is not supported in Webhook, please use `application/json` instead. For “import end to GP”,  it looks the default value is disabled. You can manually enable it on this page.
