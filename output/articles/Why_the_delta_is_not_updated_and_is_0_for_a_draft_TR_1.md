# Why the delta is not updated and is 0 for a draft TR?

It may not show the delta count for a draft TR in GP. Because draft TR only specifies bundles/language to be included, and delta calculation is heavy operation / also updated if any bundles included in the TR is updated, it does not show the count. If you resume the operation on Dashboard, it will calculate the delta strings at that point.
