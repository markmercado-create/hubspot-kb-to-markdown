# i18n.yaml Reference

Translation tasks on WebFM Automation are configured mostly through file `i18n.yaml` stored in your repository. This allows your configuration to be version controlled and flexible.

### Sample i18n.yaml

```
webfm_settings:  
  appname: "MyWebFMApp"  
  extract_as_source: "source_list"   
  
language:  
- "en_US"  
- "ja"  
- "fr"  
- zh_TW:  
  machine_translate: "pseudo-FULL"  
  
source_list:  
- pattern: "**/en-US.json"  
  resfilter: "GLOBALIZEJS"  
- pattern: "src/main/resources/**/*.properties"  
  resfilter: "JAVA2IBMJDK21-PRB"  
  
pre_translation:  
- regex: ".*"    
  checks: ["chkpii"]   
  
post_translation:  
- regex: "(.*)\\.(properties|json)$"  
  continue_after_matched: true  
  text_replace:   
  - apply_to: "all"  
    text_regex: "(\\r\\n|\\r)"   
    text_replace_value:  
      all: "\\n"   
  
- regex: "(.*)\\.properties$"  
  checks: ["src-exist", "chkpii"]  
  rename:   
    all: "$1_${language}.${srcFileExtension}"  
  
- regex: "(.*)/en-US\\.json$"  
  checks: ["src-exist", "chkpii", "eslint"]  
  rename:  
    - ja: "$1/ja.json"  
    - fr: "$1/fr.json"  
    - zh_TW: "$1/zh-Hant.json"  
  text_replace:  
  - apply_to: "first"  
    text_regex: "(\"?)${srcFilenameWithoutExt}(\"?\\s+:\\s+{)"  
    text_replace_value:  
      all: "$1${renamedFilenameWithoutExt}$2"  
  
- regex: ".*"  
  checks: ["src-exist", "chkpii"]
```

### Keys

| Key | Required | Values | Description |
| --- | --- | --- | --- |
| webfm\_settings | *optional* | appname extract\_as\_source | WebFM application settings |
| language | **required** | [list of language settings] | Source/target language settings Machine translation/pseudo translation settings |
| source\_list | **required** | [list of pii file settings] | PII file pattern Resource filter Id GP Bundle Id GP Bundle settings |
| pre\_translation | *optional* | [list of pre translation tasks] | Checks Encoding change Text content replacement |
| post\_translation | **required** | [list of post translation tasks] | Checks Encoding change Rename Text content replacement |
| post\_translation\_more\_rename | *optional* | [list of additional post translation rename tasks] | Rename |

### webfm\_settings

The `webfm_settings` stores general webfm app settings.

```
webfm_settings:  
  appname: (string) # WebFM application name  
  extract_as_source: ("all_files_in_repo" | "source_list" | "SRC_XLATE_yes" | "SRC_XLATE_no" | "SRC_XLATE_related") # WebFM dispacher settings
```

| Key | Required | Description |
| --- | --- | --- |
| `appname` | *optional* | WebFM application name |
| `extract_as_source` | *optional* | \* `source_list`**(default)**: extract new & changed files from source RTC or Git. \* `all_files_in_repo` extract new & changed files from source RTC or Git \* `SRC_XLATE_yes`, `SRC_XLATE_no`, `SRC_XLATE_related`: extract new & changed files with specific SRC\_XLATE attribute from source RTC. |

### language

The `language` stores a list of source and target **language codes**. If machine or pseudo translate need be committed back to repository, use the **language code** as key and add `machine_translate` as value.

```
language:  
- "en_US" # First language must be source language  
- "<target_language_code_1>" # Target language with human translation only  
- <target_language_code_2>: # Target language with machine / pseduo translation  
  machine_translate:  true | false | "pseudo-FULL" | "pseudo-RPX" | "pseudo-NW"   
  ...
```

| Key | Required | Description |
| --- | --- | --- |
| `<language code>` | **required** | Language code |
| `machine_translate` | *optional* | \* `false`**(default)**: use GP reviewed translation only \* `true`: use GP machine translation \* `"pseudo-FULL"`: use RPX Full-Width pseudo translation *(Recommended)* \* `"pseudo-RPX"`: use RPX Tivoli pseudo translation \* `"pseudo-NW"`: use RPX NineWay pseudo translation |

### source\_list

The `source_list` stores a list with git-style patterns, and the latter in list will override the former.

```
source_list:   
- pattern: (string)  
  resfilterId: (string)  
  gp_bundle_id: (string)  
  gp_bundle_settings: (string)  
- pattern: !(string) # string starting with `!` to exclude files matching this pattern  
  resfilterId: (string)  
  gp_bundle_id: (string)  
  gp_bundle_settings: (string)  
- pattern: (string)  
  resfilterId: "FILE-BASED"  
  gp_file_id: (string)  
  gp_file_settings: (string)  
...
```

| Key | Required | Description |
| --- | --- | --- |
| `pattern` | **required** | Use Git-style pattern: `*` matches anything except `/` `**` matches anything Starting with `!` means to exclude |
| `resfilterId` | **required** | GP resource filter ID |
| `gp_bundle_id` | *optional* | GP Language Bundle ID. Default to **generate from file path**. |
| `gp_bundle_settings` | *optional* | Serialization of the JSON object of GP bundle settings of [GP RESTful API](https://api.pipeline.g11n.ibm.com/translate/swagger/#/bundle/updateBundle). Please serialize your JSON object into **single string**. Default **null**. |
| `gp_file_id` | *optional* | GP Language File ID. Default to **generate from file path**. |
| `gp_file_settings` | *optional* | Serialization of the JSON object of GP file settings of [GP RESTful API](https://api.pipeline.g11n.ibm.com/translate/swagger/#/file/updateFile). Please serialize your JSON object into **single string**. Default **null**. |

### pre\_translation

```
pre_translation:  
- regex: (string) # use Java regular expression  
  continue_after_matched: true | false  
  checks: ["eslint", "chkpii", "gencat" ...]   
  change_encoding_to: (string | Map<string, string>)  
  text-replace:   
  - apply_to: "all" | "first" | "recursive"  
    text_regex: (string) # use Java regular expression  
    text_replace_value:  
      all: (string)  
      <lanuage code>: (string)  
      <lanuage code>:  
      - (string list item)  
      - (string list item)
```

| Key | Required | Description |
| --- | --- | --- |
| `regex` | **required** | Java regular expression to match file path |
| `continue_after_matched` | *optional* | Continue to process after current rule matched. Default **false** |
| `checks` | *optional* | List of checks to perform. Default **null** `src-exist` Check the source English file exists `"chkpii [Encoding option] [-F] [-XM msgId]"` perform general chkpii `"eslint"` perform basic eslint without eslintrc `"gencat"` performs gencat *[\*\*note: checks options](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Checks-options)* *[\*\*note: duplicate checks processing](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Duplicate-checks-processing)* |
| `change_encoding_to` | *optional* | Specify an encoding for all languages: `UTF8`, `<Charset name>`, `ANSI`, or `ASCII`. Or specify encodings for each language by a `Map<string, string>`. Default **null**. *[\*\*note: Encodings definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Encoding-changes-definition)* |
| `text-replace` | *optional* | Text content replacement settings |
| `text-replace.apply_to` | *optional* | `first`**(default)** perform regex replacement for first match only `all` perform global regex replacement `recursive` perform global regex replacement again and again until no more matches |
| `text-replace.text_regex` | **required** for `text-replace` | Java regular expression pattern to look for text in file content. Variables can be used in the regex: `${language}`, `${srcFileFullpath},` ${srcFilename}`,` ${srcFilenameWithoutExt}`,` ${srcFileExtension}`,` ${filetype}`,`${renamedFilename}`,` ${renamedFilenameWithoutExt}` *[\*\*note: Variable definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Variables-during-processing)* |
| `text-replace.text_replace_value` | **required** for `text-replace` | The replacements of `text_regex` matches. Use `all` or `<language code>` as key, and the replacement string(s) as value. Variables can be used in the regex: `${language}`, `${srcFileFullpath},` ${srcFilename}`,` ${srcFilenameWithoutExt}`,` ${srcFileExtension}`,` ${filetype}`,`${renamedFilename}`,` ${renamedFilenameWithoutExt}` *[\*\*note: Variable definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Variables-during-processing)* |

### post\_translation

The `post-translation` use Java regular expression to locate files and perform tasks on them: `checks` `change_encoding_to` `rename` `text_replace` `continue_after_matched`.

```
post_translation:  
- regex: (string) # use Java regular expression  
  continue_after_matched: true | false  
  checks: (["eslint", "chkpii", "gencat" ...] or Map<string, string>)  
  change_encoding_to: (string | Map<string, string>)  
  rename:  
    all: (string)  
    <language code>: (string)  
    <language code>:  
    - (string list item)  
    - (string list item)  
  text-replace:   
  - apply_to: "all" | "first" | "recursive"  
    text_regex: (string) # use Java regular expression  
    text_replace_value:  
      all: (string)  
      <language code>: (string)  
      <language code>:  
      - (string list item)  
      - (string list item)
```

| Key | Required | Description |
| --- | --- | --- |
| `regex` | **required** | Java regular expression to match file path |
| `continue_after_matched` | *optional* | Continue to process after current rule matched. Default **false** |
| `checks` | *optional* | List of checks to perform, or specify checks for each language by a `Map<string, List<string>>`. Default **null** `src-exist` Check the source English file exists `"chkpii [Encoding option] [-F] [-XM msgId]"` perform general chkpii `"eslint"` perform basic eslint without eslintrc `"gencat"` performs gencat *[\*\*note: checks options](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Checks-options)* *[\*\*note: duplicate checks processing](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Duplicate-checks-processing)* |
| `change_encoding_to` | *optional* | Specify an encoding for all languages: `UTF8`, `<Charset name>`, `ANSI`, or `ASCII`. Or specify encodings for each language by a `Map<string, string>`. Default **null**. *[\*\*note: Encodings definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Encoding-changes-definition)* |
| `rename` | *optional* | Rename translated files for each language. Use `all` or `<language code>` as key, and the renamed path(s) as value. Variables can be used in the regex: `${language}`, `${srcFileFullpath}`, `${srcFilename}`, `${srcFilenameWithoutExt}`, `${srcFileExtension}`, `${filetype}`,`${renamedFilename}`, `${renamedFilenameWithoutExt}` *[\*\*note: Variable definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Variables-during-processing)* |
| `text-replace` | *optional* | Text content replacement settings |
| `text-replace.apply_to` | *optional* | `first`**(default)** perform regex replacement for first match only `all` perform global regex replacement `recursive` perform global regex replacement again and again until no more matches |
| `text-replace.text_regex` | **required** for `text-replace` | Java regular expression pattern to look for text in file content. Variables can be used in the regex: `${language}`, `${srcFileFullpath}`, `${srcFilename}`, `${srcFilenameWithoutExt}`, `${srcFileExtension}`, `${filetype}`,`${renamedFilename}`, `${renamedFilenameWithoutExt}` *[\*\*note: Variable definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Variables-during-processing)* |
| `text-replace.text_replace_value` | **required** for `text-replace` | The replacements of `text_regex` matches. Use `all` or `<language code>` as key, and the replacement string(s) as value. Variables can be used in the regex: `${language}`, `${srcFileFullpath}`, `${srcFilename}`, `${srcFilenameWithoutExt}`, `${srcFileExtension}`, `${filetype}`,`${renamedFilename}`, `${renamedFilenameWithoutExt}` *[\*\*note: Variable definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Variables-during-processing)* |

#### post\_translation\_more\_rename

The `post_translation_more_rename` use Java regular expression to locate files and perform `rename` on them. This is for back-compatible with legacy WebFM project. We suggest to use only `post_translation`.

```
post_translation:  
- regex: (string) # use Java regular expression  
  continue_after_matched: true | false  
  rename:  
    all: (string)  
    <language code>: (string)  
    <language code>:  
    - (string list item)  
    - (string list item)
```

| Key | Required | Description |
| --- | --- | --- |
| `regex` | **required** | Java regular expression to match file path |
| `continue_after_matched` | *optional* | Continue to process after current rule matched. Default **false** |
| `rename` | *optional* | Rename translated files for each language. Use `all` or `<language code>` as key, and the renamed path(s) as value. Variables can be used in the regex: `${language}`, `${srcFileFullpath}`, `${srcFilename}`, `${srcFilenameWithoutExt}`, `${srcFileExtension}`, `${filetype}`,`${renamedFilename}`, `${renamedFilenameWithoutExt}`  *[\*\*note: Variable definition](https://github.ibm.com/1t1p/webfm-guide/wiki/i18n.yaml-Reference#Variables-during-processing)* |

### Notes

### Encoding changes definition

- `UTF8`: Most modern files are using `UTF8` encoding.
- `ANSI`: If you are using [ANSI](https://w3-03.ibm.com/globalization/page/2088#ANSIcp)
- `ASCII` if you are using [IBM ASCII](https://w3-03.ibm.com/globalization/page/2088#ASCIIcp).
- `<any others>`: You can specify a [Java charset name](https://docs.oracle.com/javase/7/docs/technotes/guides/intl/encoding.doc.html).

```
change_encoding_to: "UTF16-BE"
```

- Or you can use a map:

```
change_encoding_to:  
   fr: "cp1252"  
   ja: "cp932"  
   zh-TW: "cp950"
```

### Checks options

You can define a list of checks in the `pre-translation` or `post-translation` tasks. For example:

```
checks: ["chkpii", "eslint"]
```

Or define a map in `post-translation` for different languages:

```
checks:   
  fr: ["src-exist", "chkpii", "eslint"]  
  ja: ["src-exist", "chkpii -XM 809", "eslint"]  
  ko: ["chkpii(skip)"]  
  de: ["src-exist", "chkpii -F"]
```

| Available option | Description |
| --- | --- |
| `src-exist` | Check the English source file exists |
| `chkpii [Encoding option] [-F] [-XM msgId] [-LE line_limit]` | run chkpii <src file> -EN [Options] on English sources and run chkpii <translated file> <src file> -<language code> [Options] on translations. Options:  - [Encoding options] could be `-UTF8`,`-ANSI`,`-ESCU`,`-UCS2` or `-ASCII` - `-F`: Check only src file existence; bypass the internal content comparison check - `-XM msgId` Exclude specific messages. For details about CHKPII msgId, please refer to [CHKPII guilde](https://pages.github.ibm.com/globalization/classic/2190.html) - `-LE`: Line length limit |
| `chkpii(skip)` | do not run any chkpii on files specified. |
| `javac` | run javac |
| `gencat` | run gencat |
| `eslint` | run eslint **This will run basic eslint only, any customized eslintrc will not be applied.** |

### Duplicate checks processing

If the file is matching to multiple regexes, all checks of different types will be performed. e.g. In the config file below, both `eslint` and `chkpii` will be performed on `abc.json`

```
pre_translation:  
- regex: ".*\\.json"  
  continue_after_matched: true  
  checks: ["eslint"]   
- regex: ".*"  
  checks: ["chkpii"]
```

However if one type of check is defined more than once. e.g. In the config file below, only the first one (chkpii -UTF8) will be performed.

```
post_translation:  
- regex: ".*\\.json"  
  continue_after_matched: true  
  checks: ["chkpii -UTF8"] # this chkpii will be honored  
- regex: ".*"  
  checks: ["chkpii"] # this chkpii will be ignored
```

### Variables during processing

| Variable | Description | Example |
| --- | --- | --- |
| `${language}` | The `<language code>` in this yaml | `zh_TW` |
| `${langCodeAutoStyling}` | WebFM will try to style `<language code>` the same as the source path | `ja_JP` when `en_US` found in source path |
| `${srcFileFullpath}` | The original file full path before any renaming process | `app/src/nls/message_en_US.jsp` |
| `${srcFilename}` | The original file name (basename and extension) before any renaming process | `message_en_US.jsp` |
| `${srcFilenameWithoutExt}` | The original file basename before any renaming process | `message_en_US` |
| `${srcFileExtension}` | The original file extension before any renaming process | `jsp` |
| `${filetype}` | The original [Tivoli classic file type](https://github.ibm.com/1t1p/webfm-guide/wiki/Tivoli%20and%20WebFM%20supported%20filetypes) before any renaming process | `html` |
| `${renamedFilename}` | The file name (basename and extension) at the current step of processing | `message_zh_TW.jsp` |
| `${renamedFilenameWithoutExt}` | The file basename at the current step of processing | `message_zh_TW` |
