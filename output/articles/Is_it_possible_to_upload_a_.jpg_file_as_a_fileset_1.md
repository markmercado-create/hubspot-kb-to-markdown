# Is it possible to upload a .jpg file as a fileset?

No, `.jpg` is NOT supported as a fileset, just the following content types are supported by GP as bundle.

![](media_files/image-png-Jun-11-2024-06-50-25-5779-AM.png)

![](media_files/image-png-Jun-11-2024-06-50-36-7502-AM.png)

JPG cannot be translated, it must be completely re-drawn. You needs to move to a graphics type that has a text layer. SVG is typical.
