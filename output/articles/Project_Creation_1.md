# Project Creation

- Step 1: go to **Projects Manager  
  ![proj-mgr-manu](media_files/proj-mgr-manu.png)**

  

- Step 2: click **Add new Project  
  ![proj-add-new](media_files/proj-add-new.png)**

  

- Step 3: input **WebFM Project ID**, which is only used in WebFM
- Step 4: input Project Description
- Step 5: select project start date and end date of this WebFM project
- Step 6: select multiple repositories for this project
- Step 7: input E-mail(s) of who would like to get notification for any file handling events to **Email Subscription**. Usually includes GPM and other project key members
- Step 8: click **Create Project**
- Step 9: click **Manage Project Languages** to add target translation languages
- Step 10: click **Manage Project Users** to add project members
- Step 11: if you would like to update the project configuration, language list, user list, and upload GP credentials later, go to **Project Config** section to make your changes  
  ![proj-sub-menu](media_files/proj-sub-menu.png)
